## Key decisions

- **Composio key is a consumer key (`ck_`).** The v3.1 REST/SDK reject it (401), but Composio's hosted MCP accepts it (`x-consumer-api-key`), which exposes the same session meta-tools. `lib/composio-mcp.ts` uses that; `lib/agent/composio.ts` prefers the SDK automatically once a Platform `ak_` key is set. **Custom auth configs (bring-your-own OAuth app) need a Platform project**, so the GitHub *custom-app* closed loop needs an `ak_` key.
- **No free search:** Gemini grounding has 0 free quota; `gemini-2.5-flash` is closed to new users; Composio's Firecrawl search is paid ($0.007/search, not enabled). Discovery crawls the provider's own site (portal patterns, sitemap, LLM link ranking).
- **Models:** agent `3.8-flash → 3.6-flash → 3.5-flash-lite`, verifier `3.5-flash-lite`. 3.8-flash is usually 503-overloaded; `GREENLIGHT_CHAIN_ROUNDS` retries the chain.
- **Citations can't be invented:** the model cites S1/P2/C1 ids; code attaches URLs/artifacts. Verify = quote re-fetch (fuzzy) + 2nd-model support check; failures become `uncertain`.
- **Rubric:** cost is separate from difficulty unless access is partner/sales-gated (X = 2 with paid credits; Spotify = 5 because production is organizations-only with 250k MAU).
- **Gold = curated sources + agent draft + human patch.** Patches are applied by `scripts/apply-gold-patches.mts`, which re-verifies every added quote live and aborts on a miss. Gold `reviewStatus` stays `unreviewed` until Yugh reads them.
